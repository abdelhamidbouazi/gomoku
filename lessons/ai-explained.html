🎯 What is Gomoku?

Gomoku (Five in a Row) is a strategic board game played on a 19×19 grid. Two players alternate placing stones, and the goal is to create an unbroken line of five stones horizontally, vertically, or diagonally.

Special Rules in This Implementation:

  • Captures: Pattern X-O-O-X captures the two opponent stones
  • Double-Three Rule: Cannot create two "free threes" with one move
  • Capture Win: Capturing 10+ stones wins the game
  • Breakable Five: A five can be broken by capturing one of its stones

🌳 Minimax Algorithm

Minimax is a decision-making algorithm for two-player games. It explores possible future moves by simulating both players playing optimally.

Core Concept

Maximizing Player (AI): Tries to maximize the score

Minimizing Player (Opponent): Tries to minimize the score

The algorithm alternates between these two perspectives, recursively exploring the game tree.

✂️ Alpha-Beta Pruning

Alpha-beta pruning is an optimization that eliminates branches that cannot affect the final decision. This can reduce the search space by orders of magnitude!

How It Works

  • Alpha (α): Best score MAX player can guarantee (starts at -∞)
  • Beta (β): Best score MIN player can guarantee (starts at +∞)
  • Pruning Rule: If β ≤ α, stop exploring this branch

Pruning Example

MAX (α=-∞, β=+∞)
↙ ↘
Move A → Score: 5
Move B → Exploring...
↓
MIN (α=5, β=+∞)
↙ ↓ ↘
Child 1: -2
Child 2: PRUNED!
Child 3: PRUNED!
Why pruned? After finding -2, β becomes -2. Since -2 ≤ 5 (β ≤ α), we know MAX won't choose Move B (it already has Move A with score 5). No need to explore remaining children!
3-10x Speed Improvement
b^(d/2) Best Case Complexity
30-70% Nodes Pruned

🔄 Iterative Deepening

Instead of searching to a fixed depth, iterative deepening searches depth 1, then 2, then 3, and so on until time runs out.

  • Better Move Ordering: Results from shallow searches improve deep searches

🧠 Heuristic Evaluation

Evaluation Formula

Score = AI_Patterns - Opponent_Patterns + Captures_Bonus

Positive score = good for AI | Negative score = good for opponent

Capture Checking

After placing a stone, check all 8 directions (4 directions × 2 ways each):

  1. Check 3 cells away in that direction
  2. Pattern must be: Your Stone → Opponent → Opponent → Your Stone
  3. If found, remove the two opponent stones
  4. Add 2 to your capture count

Undo Support

The capture function returns a history of all changes:

history = [(x1, y1, old_value1), (x2, y2, old_value2), ...]

This allows the AI to try a move, evaluate it, then undo it perfectly - critical for minimax search!

⚠️ Double-Three Rule

You cannot place a stone that creates two or more "free threes" simultaneously (unless it captures).

What is a "Free Three"?

A three-in-a-row where one more stone can create an open four (which guarantees a win).

_ X X X _
Free Three (Open)

Can become open four with one move

# X X X #
NOT a Free Three (Closed)

Cannot become open four

Why This Rule Exists

Without this rule, the first player could create multiple simultaneous threats that are impossible to defend against, making the game unbalanced.

Checking Algorithm

  1. Temporarily place the stone
  2. Check if it made any captures (if yes, move is legal)
  3. Count how many free-threes exist at this position
  4. If count ≥ 2, the move is illegal
  5. Undo the temporary placement

💥 Breakable Five Rule

A five-in-a-row can be broken by capturing one of its stones! The game only ends when a five exists that cannot be broken.

Terminal State Check Order

1. Check Capture Wins (10+ captures)
↓
2. Check Five-in-a-Rows
↓
3. Check if Five Can Be Broken by Capture
↓
If unbreakable → Game Over!
If breakable → Game Continues
def get_terminal_score(board, captures):
    # 1. Capture wins take priority
    if captures[AI] >= 10: return WIN_SCORE
    if captures[OPP] >= 10: return LOSE_SCORE
    
    # 2. Check for fives
    ai_has_five = has_player_won(board, AI)
    opp_has_five = has_player_won(board, OPP)
    
    # 3. Check if five can be broken
    if ai_has_five and not can_break_by_capture(board, AI):
        return WIN_SCORE
    if opp_has_five and not can_break_by_capture(board, OPP):
        return LOSE_SCORE
    
    return None  # Game continues

🎯 Candidate Move Generation

Instead of checking all 361 cells, only check empty cells near existing stones.

Approach Cells Checked Speed
Naive (all cells) 361 ❌ Very Slow
Neighbor-based (radius=2) ~20-50 ✅ 7-18× Faster

Algorithm

  1. Find all stones on the board
  2. For each stone, check neighbors within radius 2
  3. Collect all empty neighbors into a set (removes duplicates)
  4. Return as list of candidate moves
NEIGHBOR_RADIUS = 2

for stone in all_stones:
    for dy in range(-RADIUS, RADIUS + 1):
        for dx in range(-RADIUS, RADIUS + 1):
            neighbor = stone + (dx, dy)
            if is_empty(neighbor):
                candidates.add(neighbor)

Why Radius = 2?

Radius 1: Too restrictive, misses some tactical moves

Radius 2: Sweet spot - captures most relevant moves

Radius 3+: Too many candidates, diminishing returns

Minimax with Alpha-Beta Pruning

def minimax(board, captures, depth, alpha, beta, maximizing, ...) -> float:
    """
    Recursive minimax with alpha-beta pruning.
    Returns: Best score from this position
    """
    # Base cases
    terminal = get_terminal_score(board, captures)
    if terminal is not None:
        return terminal
    
    if depth == 0:
        return evaluate_board(board, captures)
    
    # Check transposition table
    key = (board_key(board), captures[AI], captures[OPP], player, depth)
    if key in table:
        return table[key]
    
    # Get and order moves
    moves = get_legal_moves(board, current_player, captures)
    moves = order_moves(board, captures, current_player, moves)
    
    # Maximizing player (AI)
    if maximizing:
        best = -∞
        for move in moves:
            history = apply_move_with_captures(board, move, AI_PLAYER, captures)
            score = minimax(board, captures, depth-1, alpha, beta, False, ...)
            undo_move_with_captures(board, captures, AI_PLAYER, history)
            
            best = max(best, score)
            alpha = max(alpha, best)
            
            if beta <= alpha:  # Prune!
                break
        
        table[key] = best
        return best
    
    # Minimizing player (Opponent) - similar but inverted
    else:
        best = +∞
        for move in moves:
            history = apply_move_with_captures(board, move, OPP, captures)
            score = minimax(board, captures, depth-1, alpha, beta, True, ...)
            undo_move_with_captures(board, captures, OPP, history)
            
            best = min(best, score)
            beta = min(beta, best)
            
            if beta <= alpha:  # Prune!
                break
        
        table[key] = best
        return best

Board Evaluation

def evaluate_board(board: Board, captures: Dict[int, int]) -> float:
    """
    Heuristic evaluation from AI perspective.
    Positive = good for AI, negative = good for opponent.
    """
    # Score patterns for both players
    ai_score = score_player(board, AI_PLAYER)
    opp_score = score_player(board, OPPONENT_PLAYER)
    
    # Pattern difference
    score = ai_score - opp_score
    
    # Capture bonus
    score += captures[AI_PLAYER] * 1200
    score -= captures[OPPONENT_PLAYER] * 1200
    
    return score

def score_player(board: Board, player: int) -> float:
    """Find and score all patterns for one player."""
    total = 0.0
    
    for y in range(BOARD_SIZE):
        for x in range(BOARD_SIZE):
            if board[y][x] != player:
                continue
            
            # Check each direction
            for dx, dy in DIRECTIONS:
                # Only count each streak once
                if is_continuation(board, x, y, dx, dy, player):
                    continue
                
                # Count consecutive stones
                length = count_line(board, x, y, dx, dy, player)
                
                # Check open ends
                open_ends = count_open_ends(board, x, y, dx, dy, length, player)
                
                # Add pattern score
                total += pattern_score(length, open_ends)
    
    return total

def pattern_score(length: int, open_ends: int) -> float:
    """Score a single pattern."""
    if length >= 5:
        return 50_000.0
    
    base = {1: 3, 2: 25, 3: 220, 4: 4_000}.get(length, 0)
    
    if open_ends == 2:
        return float(base)
    elif open_ends == 1:
        return float(base) * 0.35
    else:
        return float(base) * 0.08

Capture Logic with Undo

def apply_move_with_captures(
    board: Board,
    x: int, y: int,
    player: int,
    captures: Dict[int, int]
) -> List[Tuple[int, int, int]]:
    """
    Place move and apply captures.
    Returns history for undo: [(x, y, old_value), ...]
    """
    # Place stone
    board[y][x] = player
    history = [(x, y, EMPTY)]
    
    opponent = get_opponent(player)
    
    # Check all 8 directions for captures
    for dx, dy in DIRECTIONS:
        for sign in (1, -1):
            sdx, sdy = dx * sign, dy * sign
            
            # Check pattern: X-O-O-X
            x1, y1 = x + sdx, y + sdy
            x2, y2 = x + 2*sdx, y + 2*sdy
            x3, y3 = x + 3*sdx, y + 3*sdy
            
            if not all_in_bounds(x1, y1, x2, y2, x3, y3):
                continue
            
            if (board[y1][x1] == opponent and
                board[y2][x2] == opponent and
                board[y3][x3] == player):
                
                # Record changes
                history.append((x1, y1, opponent))
                history.append((x2, y2, opponent))
                
                # Remove stones
                board[y1][x1] = EMPTY
                board[y2][x2] = EMPTY
                
                # Update count
                captures[player] += 2
    
    return history

def undo_move_with_captures(
    board: Board,
    captures: Dict[int, int],
    player: int,
    history: List[Tuple[int, int, int]]
) -> None:
    """Undo a move perfectly."""
    # Restore capture count
    removed_count = len(history) - 1
    captures[player] -= removed_count
    
    # Restore all cells
    for x, y, old_value in reversed(history):
        board[y][x] = old_value

Move Ordering

def order_moves(board, captures, player, moves) -> List[Move]:
    """Sort moves from most to least promising."""
    return sorted(
        moves,
        key=lambda m: move_order_score(board, captures, player, m),
        reverse=True  # Highest score first
    )

def move_order_score(board, captures, player, move) -> float:
    """Quick score for move ordering."""
    x, y = move
    score = 0.0
    
    # 1. Center bias (slight)
    center = BOARD_SIZE // 2
    distance = abs(x - center) + abs(y - center)
    score -= distance * 2
    
    # 2. Try the move
    history = apply_move_with_captures(board, x, y, player, captures)
    
    # 3. Immediate win? Huge priority!
    terminal = get_terminal_score(board, captures)
    if terminal and (
        (player == AI_PLAYER and terminal > 0) or
        (player == OPPONENT_PLAYER and terminal < 0)
    ):
        score += 1_000_000
    
    # 4. Capture move? High priority
    if len(history) > 1:
        score += 20_000
    
    # 5. Add heuristic
    raw = evaluate_board(board, captures)
    score += raw if player == AI_PLAYER else -raw
    
    # 6. Undo
    undo_move_with_captures(board, captures, player, history)
    
    return score

🔗 Putting It All Together

Complete AI Flow

1. Entry: choose_best_move(board, ...)

↓ Get legal moves

↓ Quick win/block check

2. Iterative Deepening: depth = 1, 2, 3...

↓ Order moves (best first)

3. For each move:

↓ Apply move + captures

↓ Call minimax(depth-1, ...)

4. Minimax recursively:

↓ Check terminal / depth limit

↓ Check transposition table

↓ Get & order legal moves

↓ Try each move recursively

↓ Alpha-beta prune when possible

↓ Cache result in table

5. Base case: Evaluate board

↓ Score AI patterns

↓ Score opponent patterns

↓ Add capture bonuses

↓ Return score

6. Unwind recursion, undo moves

7. Return best move found
